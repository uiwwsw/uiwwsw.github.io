# Final Design QA & Handoff

본 문서는 간격/정렬/타이포, 다크 모드, 컴포넌트 스테이트, 문서화 범위에 대한 최종 QA 체크리스트와 결과를 정리합니다.

## QA 체크리스트
- [x] 전역 타이포/팔레트: 기본 폰트 스택과 CSS 변수 기반 팔레트를 검증하고, 다크 테마 기본값을 확인했습니다.
- [x] 간격·정렬: 최대 폭 `max-w-6xl` 컨테이너, 카드 그리드의 `gap` 사용, 모바일/데스크톱 여백(`px-5`/`px-6`, `py-10`) 균형 확인.
- [x] 컴포넌트 스테이트: 헤더 링크 및 모바일 토글의 hover/focus/active 상태, 카드의 focus-visible 스타일, 버튼/배지의 눌림 상태를 점검했습니다.
- [x] 접근성: 네비게이션 `aria-current`, 모바일 메뉴 `aria-expanded`/`aria-controls`, 포커스 링 대비를 확인했습니다.
- [x] 반응형: 헤더 네비게이션의 md 브레이크포인트 전환, 카드/그리드의 1→2→3열 전환, 모바일 메뉴 시트 동작 확인.
- [x] 콘텐츠 레이아웃: 블로그 프리뷰/OSS 섹션에서 텍스트 대비와 라인 길이를 점검했습니다.

## 발견사항 및 수정 내역
- 기본 다크 테마가 CSS 변수의 `color-scheme`와 불일치해 접근성 도구 인식에 혼선이 있던 부분을 수정했습니다. 이제 `data-theme="dark"` 속성으로 전역 팔레트가 일관되게 적용됩니다.
- 바디 클래스의 중복 색상 정의를 제거하여 전역 토큰(배경/텍스트)과 레이아웃 그라디언트가 충돌하지 않도록 정리했습니다.
- README를 신규 작성해 설치/개발/배포/콘텐츠 작성 흐름을 명시했습니다.

## 다크 모드 옵션 결정
- 기본값: 다크 모드 고정 (`<html data-theme="dark">`).
- 토글: 현재는 제공하지 않습니다. 추후 라이트 모드가 필요하면 `data-theme="light"` 속성을 토글하는 스위치를 추가하면 됩니다(팔레트 토큰은 이미 정의됨).
